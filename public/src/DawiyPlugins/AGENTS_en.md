# DAWIY Plugin Specification for AI Agents and Developers

This document provides detailed specifications for AI agents and developers creating and managing plugins within the `public/src/DawiyPlugins` directory.
It is designed to provide enough context and rules for plugins to be implemented effectively even if only the information within this directory is available.

## Directory Structure and Loading Mechanism

- **Path**: `public/src/DawiyPlugins/`
- **Automatic Loading**: The system scans all `.ts` files within this directory and its subdirectories.
- **Exclusions**: `PluginTemplate.ts` and `IDawiyPlugin.ts` are automatically ignored by the system.
- **No Manual Registration**: Plugins are recognized simply by creating the file. There is no need to edit other files like `DawiyPluginController.ts`.

## Implementation Protocol (Strict Adherence)

When generating plugins, follow these configuration rules:

1. **File Placement**:
    - Recommended: `public/src/DawiyPlugins/<PluginName>/<MainFile>.ts`
    - Creating a subdirectory for organization is highly recommended.

2. **Class Definition**:
    - Must extend the `DawiyPluginBase` class.
    - Must use the `@DAWIYPlugin` decorator.
    - The class MUST be the **`export default`**.

3. **Constructor**:
    - Must have the signature `constructor(app: App)` and call `super(app)`.

4. **Configuration File (plugin.json) [Optional]**:
    - Use `plugin.json` for metadata only. Dependency management via this file is deprecated.
    - Use `this.dynamicImport` for loading external libraries.

5. **Grouping [Optional]**:
    - To specify a plugin group, set the `group` property (default is "General").
    ```typescript
    group = "My Custom Group";
    ```


## External Libraries (Dynamic Import)

We utilize a simplified dynamic import mechanism.

```typescript
// Recommended
const module = await this.dynamicImport('https://cdn.jsdelivr.net/npm/tonal/browser/tonal.min.js');
```

## Template Code

Use the following template as a basis for implementation:

```typescript
import App from "../../App"; // Adjust path based on depth
import { DAWIYPlugin } from "../IDawiyPlugin";
import DawiyPluginBase from "../DawiyPluginBase";

@DAWIYPlugin
export default class MyAgentPlugin extends DawiyPluginBase {
    // Unique ID (ensure it doesn't conflict with other plugins)
    id = "my-agent-plugin";
    // Name displayed in the UI
    name = "My Agent Plugin";
    // Brief description of functionality
    description = "A plugin generated by an AI agent.";

    constructor(app: App) {
        super(app);
    }

    /**
     * Renders the UI
     * @param container The drawing area assigned to the plugin (e.g., a div)
     */
    public override render(container: HTMLElement) {
        this.container = container; // Optional: DawiyPluginBase already holds this if you assign it, but usually you just use the arg.
        container.innerHTML = ''; // Clear for re-rendering
        
        // Styling (inline styles recommended, or class definitions)
        container.style.padding = "10px";
        container.style.color = "#ecf0f1";
        container.style.overflowY = "auto";

        const title = document.createElement("h3");
        title.textContent = this.name;
        container.appendChild(title);

        const btn = document.createElement("button");
        btn.textContent = "Execute";
        btn.onclick = () => this.doAction();
        container.appendChild(btn);
    }

    /**
     * Called when the plugin is displayed
     */
    public override onActivate() {
        // Register event listeners if necessary
    }

    /**
     * Called when the plugin is hidden or closed
     */
    public override onDeactivate() {
        // Cleanup processing
    }

    private async doAction() {
        console.log("Action executed by " + this.name);
        
        // Example: Dynamic Import
        // const lib = await this.dynamicImport('https://example.com/lib.js');
    }
}
```

## API Access and Operations (Context)

You can access the DAW's main components through the `this.app` instance (of the `App` class).

### Key Controllers

- **`app.tracksController`**: Track management
  - `app.tracksController.selectedTrack`: The currently selected track.
  - `app.tracksController.trackList`: Array of tracks.
  - `app.tracksController.createAudioTrack()`: Create new tracks, etc. (Verify method names in implementation).
- **`app.regionsController`**: Region management (Audio clips, MIDI notes).
- **`app.host`**: Playback and transport management.
  - `app.host.play()`: Play.
  - `app.host.pause()`: Pause.
  - `app.host.transportPosition`: Current playback position.

### State Changes (Undo/Redo)

Operations that change the DAW state (adding tracks, moving notes, etc.) should ideally go through the `app.doIt(command)` pattern to support Undo/Redo. However, you can access controllers directly for simple reads or temporary operations.

### Important Notes

- Always build the UI within the `container` passed as an argument. Do not append directly to global elements like `document.body`.
