# Muse Mate (みゅーず・めいと！) 開発ドキュメント

## 概要 (Overview)
「みゅーず・めいと！」は、DAW（音楽制作ソフト）であるDAWIY上での音楽制作のモチベーション向上を目的とした、AIサポート・コンパニオンプラグインです。
ユーザーが「DAWを開く動機づけ」を得られるよう、オリジナルキャラクター「緒守付 にちよ（おもづく にちよ）」とのコミュニケーションやゲーミフィケーション要素を取り入れています。

## 現在の実装状況と機能 (Current Features)

### 1. UI・レイアウト
- **サイドバー配置**: 他のUIコンポーネント（AIアシスタント等）と同様に、メインUIを左側に押し出す形（相対配置）で右側に表示されます。
- **リサイザー機能**: サイドバーの左端をドラッグすることで、ウィンドウ幅を自由に調整可能です。

### 2. チャット・AI連携 (ChatEngine.ts)
- **マルチLLM対応**: Gemini API および OpenAI API に対応しています。
- **動的モデル取得**: APIキー入力時に、現在利用可能な最新モデルのリストを自動取得・フィルタリングしてプルダウンに反映します（不要なモデルは除外済み）。
- **音声入力**: Web Speech APIを利用し、マイクからの音声入力を文字起こしして送信できます（無音時の自動停止エラーにも対応済み）。
- **音声合成**: COEIROINKのローカルAPI（デフォルト: `http://127.0.0.1:50032`）を利用して、AIの返答を音声で読み上げます。

### 3. ゲーミフィケーション・便利機能 (GameLogic.ts)
- **好感度システム (Affection)**: DAW上の操作（例：リージョンの追加）やチャットでの会話をトリガーに、キャラクターの好感度スコアが上昇する仕組みの基礎が実装されています。
- **ポモドーロタイマー**: 25分の集中タイマー機能が実装されており、作業の区切りをつけることができます。

## ディレクトリ構成と役割 (Architecture)
- `MuseMatePlugin.ts`: プラグインのエントリポイント。UIの構築、設定画面の描画、各モジュール（ChatEngine, GameLogic等）の結合を担当。
- `ChatEngine.ts`: LLM（Gemini/OpenAI）との通信、利用可能モデルの取得、音声認識（Web Speech API）、音声合成（COEIROINK）の制御を担当。
- `GameLogic.ts`: 好感度スコアの計算と保存、ポモドーロタイマーの管理を担当。
- `CharacterUI.ts`: キャラクターの描画領域。現在はプレースホルダーとしての実装になっています。
- `MuseMate.css`: プラグイン専用のスタイルシート。

## 今後の実装予定・引き継ぎ事項 (Future Directions)

   現在はピンク色のプレースホルダーが表示されていますが、将来的にはPixi.jsやLive2D Cubism等を用いて「緒守付 にちよ」のアニメーションを実装する予定です。
