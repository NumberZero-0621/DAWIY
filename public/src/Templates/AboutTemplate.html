Contributors
Wam Open Studio is a Work-In-Progress project by Antoine Vidal-Mazuy, Michel Buffa and Samuel Demont. It is based on the Web Audio Modules standard (WAM), which is an open source project that aims to make audio plugins available for the Web platform (aka VSTs for the Web). It has been developed as a showcase for the WAM standard, and to help developers understand how to use it. You can find the DAW source code on Github. If you want to contribute, please contact us by email (michel.buffa@univ-cotedazur.fr, antoine.vidalma@gmail.com) or in the #webaudio / webaudiomodules slack channel (get invitation here : https://web-audio-slackin.herokuapp.com/).
Special thanks
Thanks to Paul Adenot from Mozilla for his help and tools: his Ring buffer, metronome and latency tester code has been adapted and included in this DAW. Original code can be found in Paul's GitHub repo.
Thanks also to Quentin Beauchet for his help and his contributions with the Pedalboard / plugin manager (wam-bank).

開発者
Wam Open Studioは、Antoine Vidal-Mazuy、 Michel Buffa、Samuel Demontによるプロジェクトです（開発継続中）。 これは、Web Audio Modules standard (WAM) に基づいています。 WAMは、Webプラットフォームでオーディオプラグイン（Web用VSTなど）を利用可能にすることを目的としたオープンソースプロジェクトです。 このDAWは、WAM標準のショーケースとして、また開発者がその使用方法を理解するのを助けるために開発されました。 ソースコードはGithubで確認できます。 貢献したい場合は、メール (michel.buffa@univ-cotedazur.fr, antoine.vidalma@gmail.com) またはSlackチャンネル #webaudio / webaudiomodules (招待はこちら) でご連絡ください。

DAW + DIY = DAWIY
「自分好みのDAW環境をDIYする共通プラットフォーム」
…を目指しています。
目的
  • ・ DAWでもユーザ主導の設計・展開を！
  • ・ 誰もが機能を追加・改良できる「DAWツールキット」を目指して
  • ・ もっと思い通りに、もっと手早く、もっとわかりやすくやりたい
  • ・ もっと自由に音作りがしたい！
  • ・ 作曲を、もっと楽しく！
  • ・ クリエイターが理想の環境を自力で手に入れ、
       音楽の可能性をさらに探究できる未来を目指す
